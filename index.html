04 — QUESTIONS

Before you begin.

A few practical details about the adapter and its current release.

Is this an official Capcom or PlayStation product?+

No. This is an independently developed, unofficial enhancement. Onimusha, DualSense, PlayStation and other marks belong to their respective owners.

Which game and platform does it support?+

The target is the Steam PC version of Onimusha: Way of the Sword on Windows 10/11 x64. It is not a PlayStation console mod and does not include the game.

Is the manager available in English?+

Not yet. The current manager interface is in Chinese. Gauntlet voice playback can be set to Chinese or Japanese; an English voice option is not included in this release.

Does it need an internet connection to activate?+

No. The license is issued for a device code and can be entered offline. You will need to obtain the installer and activation key from the seller.

What if I already own an earlier version?+

Install the new version over the existing installation. An in-place update keeps valid activation, trial time and personal settings. Uninstalling first removes activation and settings.

Will Windows show a security warning?+

Version 2.1.0 is not code signed, so Windows may show an unknown publisher or SmartScreen warning. Verify the installer SHA-256 below against the seller's copy before running it.
